## 薛定谔的星号：在观测之前，它同时是左括号、右括号和空气

上次从多元宇宙里筛出 1430 条合法时间线之后，我大约是飘了。连夜写了一篇论文投给《物理评论》，标题是《论括号生成与多世界诠释的等价性》。

三天后，拒稿信到了。意见只有一行："本文的创新点在于证明了作者不适合做物理。"

行吧。物理学界不接纳我，所幸力扣向来不计较这些。它的判题系统只观测我的代码，不观测我的精神状态。

于是我打开力扣。首页迎面推来一道题：

> 给一个只包含 `(`、`)` 和 `*` 的字符串，判断它是否有效。其中 `*` 可以变成 `(`、`)` 或者空字符串。

我看着题面，沉默了——这不就是一个残缺宇宙么：有些位置已经坍缩成了确定的 `(` 或 `)`，有些还悬在叠加态里当 `*`。然后问我：它有没有可能活？

比如示例 `(*))`。四个位置里，三个已经坍缩，只剩那个 `*`——它同时是左括号、右括号、和空气：三种状态的叠加。问：存不存在至少一种坍缩方式，让这个宇宙的括号合法闭合？

注意措辞：**存不存在**。

这是存在性证明，不是构造性证明。我不需要知道 `*` 坍缩成了**什么**，只需要知道它**能不能**让全局最终合法。

这大概是量子力学里最让人抓狂的一类问题：你不需要观测到具体状态，只需要证明"允许的状态集合非空"。

------

#### 一、概率云与三种形变

既然只问"能不能活"，那就不需要展开每条时间线。我只需要知道一件事：**所有可能状态的边界在哪里。**

每处理一个字符，不同的 `*` 坍缩方式，会把系统导向不同的"未匹配左括号数"。这些可能的值散布在数轴上，像一团**概率云**——粒子不在某个确定位置，而是弥散在一片区域里。

所以我不用追踪云里的每一个点，只需追踪它的**左边界 `lo` 和右边界 `hi`**。

但等等——两个整数真能描述一整团云？万一可能的值中间有空洞呢？比如能到达 1 和 3，却到不了 2？

关键在于：**这团云始终是连续实心的，没有空洞**。因为 `*` 有三种选择：+1、-1、和不变。如果遇到 `*` 前未匹配数是 `x`，那么遇到之后可能是 `x-1`、`x`、`x+1`。区间从 `[x, x]` 膨胀为 `[x-1, x+1]`，中间没有空洞。

所以，两个整数就是完整描述。`[lo, hi]` 内每一个整数值，都至少对应一种合法的坍缩路径。

每读入一个字符，概率云就发生一次形变。只有三种情况：

遇到 **`(` —— 平移。**左括号已坍缩：所有宇宙的未匹配左括号数必然 +1，整团云右移一格 `lo += 1, hi += 1`。

遇到 **`)` —— 平移。**右括号已坍缩：所有宇宙的未匹配左括号数必然 -1。整团云左移一格 `lo -= 1, hi -= 1`。

遇到 **`*` —— 扩散。** 唯一处于叠加态的量子位。三种坍缩方向同时存在：变成 `(` 则未匹配数 +1，变成 `)` 则未匹配数 -1，变成空气则不变。最悲观的情况（尽量当 `)`）：`lo -= 1`；最乐观的情况（尽量当 `(`）：`hi += 1`。云同时向两边膨胀，宽度 +2：`lo -= 1, hi += 1`

就这三种操作。整个算法就是反复对一团概率云做形变——直到读完所有字符。

------

#### 二、不能穿过的墙

但这团概率云不是无限自由的。它有一堵不能穿越的墙，就在 `0` 的位置。

原因很简单：**未匹配左括号数不能为负。** 负数意味着某个前缀里 `)` 比 `(` 多——右括号凭空冒出来没有左括号配对，`x < 0` 的状态在物理上非法。

概率云可以贴着这堵墙，但不能穿过去。

于是有了第一条约束：**`lo = max(lo, 0)`。**

当 `*` 的扩散把 `lo` 拉到 `-1` 时，意味着最悲观路径（把这个 `*` 当 `)` ）会导致前缀非法——那条路撞墙了。但 `*` 还有退路：当空气。最悲观路径退而求其次，路径中某个原本打算当 `)` 的 `*`，退而求其次当了空串，`lo` 贴着墙面停在 `0`。

以及第二条约束：**`hi < 0`，全线湮灭。**

如果连 `hi`（最乐观估计），都跌进了禁区——意味着即使所有 `*` 全部当 `(`，未匹配数仍然为负。整团概率云已经完全在墙的左边，没有任何合法状态存活。直接 `return False`。

这两条约束，每读一个字符就需要检查一次。因为每观测一个量子位，云都会形变，都有可能撞墙、或者越界。

扫描完全部字符，概率云不再形变，定格在数轴上。

回到问题本身：合法括号串要求所有左括号都有右括号配对——等价于字符串读完时，未匹配左括号数恰好为 0。

所以问题变成：**0 这个点，是否仍在云的覆盖范围 [lo, hi] 内？**

答案藏在约束里。因为云撞墙就会被裁剪，`lo` 永远 ≥ 0。而 `hi` 又永远 ≥ `lo`。整团云的左边界不可能低于 0。

那么判断“0 在不在 `[lo, hi]` 里”，就等价于判断“左边界是不是贴到了 0”：

- 如果 `lo == 0`：云贴着墙，覆盖了原点。存在至少一条路径能走到 0。宇宙存活，返回 `True`。
- 如果 `lo > 0`：云整体飘在原点右边，连最悲观的路径都还剩着未匹配的左括号。没有任何路径能归零。宇宙不合法，返回 `False`。

```python
def checkValidString(s: str) -> bool:
    lo = hi = 0                     # 概率云初始状态：一个点，位于原点    
    
    for c in s:
        if c == '(':
            lo += 1
            hi += 1
        elif c == ')':
            lo -= 1
            hi -= 1
        else:  # '*'
            lo -= 1
            hi += 1
        
        # 整团云在墙左边 → 全灭
        if hi < 0:
            return False
        
        # 撞墙裁剪：左边界不可穿墙
        lo = max(lo, 0)
    
    # 0 在云内 → 存在合法坍缩路径
    return lo == 0
```

时间 O(n)，空间 O(1)。从头到尾不用记录任何一个具体的宇宙长什么样，只追踪了概率云的上下边界。

我不必知道它最终坍缩成了什么。只需证明——**它能坍缩成合法的**。

这就是存在性证明的美妙之处。

#### 尾声

后来我发现这个题目藏了个绝妙的性质：

字符串里 `*` 越多，概率云越宽，0 越容易被覆盖，存活概率越大。

于是我连夜修改了简历策略——把“精通”全改成了“熟悉”，把“熟悉”改成了“了解”。每一行都留足叠加态，让 HR 自己去坍缩。

薛定谔：“你这不叫量子力学，叫注水。”

我：“这叫增大系统的自由度。”
