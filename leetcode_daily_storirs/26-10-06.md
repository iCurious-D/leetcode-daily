## 我磕的括号 CP，连 ASCII 都在发糖

我最近磕 CP 磕得有点上头。具体来说：看到 `(` 会哭，看到 `)` 会笑，看到它们配对成功会原地鼓掌。

室友以为我疯了，我说：“你不懂，我在见证爱情。”

`(` 和 `)` 就是天选 CP：每个 `(` 必须配一个 `)`，且 `)` 不能抢跑——你不能还没遇到人就先宣布脱单。

今天的剧情是：给一串括号，数数有多少个括号在单相思，需要空降外援。

------

#### 一、别急着上栈

看到括号匹配，第一反应总是栈。

这不能怪我——教材讲栈，第一个例子是括号匹配；面试考栈，第一道题也大概率是括号匹配。

看到括号不写栈，就像吃饺子不蘸醋，总觉得少了点仪式感。

但这题问的不是“谁跟谁配了”，而是“还差几个才能全配上”。

数数的活，用不着栈。一个整数就够了。

我管它叫 `bal`，全称 `balance`。但私心里，我更愿意叫它 **bachelor**：当前还有几个左括号在单身等待。

------

#### 二、整数走天下

从左往右扫一遍，像办一场括号相亲大会。

遇到 `(`：来了个左括号，进入单身等待区。`bal += 1`。

遇到 `)`：来了个右括号，去等待区牵手。先让 `bal` 减一。如果减完非负，说明等待区有人，成功牵走一个；如果减成了负数，说明这个 `)` 来的时候等待区是空的，而这个 `)` 硬要配对。

怎么办？只能从场外空降一个 `(`，强行安排。

用 `ans` 记录空降了多少个左括号。每空降一个，`ans += 1`，再把 `bal` 拉回 0，恢复现场。

扫完字符串：

- `ans`：已经空降的左括号数；
- `bal`：扫完了还在苦等的左括号数。

`ans + bal`——空降的加上苦等的，就是要替它们安排的外援总数。

```python
def minAddToMakeValid(s: str) -> int:
    bal = ans = 0
    for c in s:
        bal += 1 if c == '(' else -1
        if bal < 0:		# 来了个 ')'，但前面没有 '(' 可以配
            ans += 1    # 空降一个 '(' 在它前面
            bal = 0		# 空降的 '(' 当场被这个 ')' 牵走，等待区归零
    return ans + bal	# 空降的 + 苦等的
```

时间 O(n)，空间 O(1)。

------

#### 三、换个角度数

还可以换个姿势：不数谁落单，数谁成功脱单了。

原串里能内部配对的括号，已经成双成对，不用管。剩下的全是单身狗，每一个都需要一个外援。

所以，答案 = 总长度 - 2 × 能配对的括号数

```python
def minAddToMakeValid(s: str) -> int:
    matched = depth = 0
    for c in s:
        if c == '(':
            depth += 1
        elif depth > 0:
            depth -= 1
            matched += 1
    return len(s) - 2 * matched
```

第一种解法在数“还剩几个单身”，第二种解法在数“成功脱单了几对”。殊途同归。

------

#### 尾声

冷知识：ASCII 码表里，`(` 是 40，`)` 是 41，连号。

磕 CP 的看到这里直接泪目——连编码都是连号，官方按头认证，正主亲自发糖，这叫天选，这叫官配！

室友路过，瞥了一眼屏幕：“你又在磕？”

我：“不，我在给官配清理拆家党。”
