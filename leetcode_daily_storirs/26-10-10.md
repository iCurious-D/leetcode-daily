## 智叟：又移？愚公：吾有 O(n log n)之法

北山愚公者，年且九十，面山而居。

自太行、王屋二山为夸娥氏二子负去，天帝闲甚，乃更新版本，于愚公门前列山两排。

一排曰 `nums1`，一排曰 `nums2`，各含 `n` 座山头。过路费以**两排山头差值的平方和**计：同下标两山头，高下相减，取绝对值，是为差值 `diff[i] = abs(nums1[i] - nums2[i])`；再平方累加，便是过路费。

差一寸收一厘，差百寸收万厘，专治头铁。

愚公惩差值平方和之大，过路费之贵也，聚室而谋曰：“吾与汝毕力**削峰平差**，可乎？” 

杂然相许。其妻献疑曰：“以君之力，曾不能损魁父之丘，如 `nums1`、`nums2` 何？且焉置土石？”

愚公曰：“天帝赐二令：`k1` 可调 `nums1`，`k2` 可调 `nums2`。每用一令，可改一山头，或 `+1` 或 `-1`。不必搬土运石，只消以令加减山高。”

其妻曰：“二令虽各掌一排，然削高、垫低，皆可缩差。何不并为一用？”

愚公曰：“善哉！吾与汝同见。所求者，诸差 `diff` 缩减耳。合二令为一账：`k = k1 + k2`。”

其妻又曰：“若合后之 `k`，逾于诸差之和，则如之何？”

愚公曰：“则 `return 0` 。`k` 既有余，诸差尽可削零，平方和归零，过路费即零，吾等白走耳。”

其妻曰：“善。”

愚公取竹简，书码数行：

```python
diff = [abs(a - b) for a, b in zip(nums1, nums2)]
k = k1 + k2

if k >= sum(diff):
    return 0
```

子孙：这 append 是海平面？ 

愚公：对，最后总得有个 0 兜底。

------

智叟闻之，拊掌大笑，曰：“甚矣，汝之不惠！合令虽妙，然 k 多至 10^9。汝欲一寸一寸削之乎？以残年余力，差未平，人先老矣！” 

智叟笑而止之曰：“甚矣，汝之不惠！合令虽妙，然 `k` 多至 10^9。汝欲一寸一寸削之乎？以残年余力，差未平，人先老矣！” 

愚公长息曰：“汝心之固，固不可彻。逐寸而削，如以瓢舀海，徒费光阴。吾有 `O(n log n) `之法：**降序排列，按层削峰**。” 

愚公取新简，不画真山，只画差值：将每个 `diff[i]` 画作一峰，峰高即差值，从高到低排好：“此非真山，乃差值所化之峰。平差，即削此诸峰也。” 又于队尾补一 `0`，指曰：“零者，两山齐平也。补于队尾，作最后一层。如此，每层皆有下一层可比，不怕越界。”

```python
diff.sort(reverse=True)
diff.append(0)
```

智叟大惑：“为何偏从最高峰削起？”

愚公曰：“此乃平方之性也。设一峰高 `x` 寸，削去一寸至 `x-1`，平方由 `x²` 变为 `(x-1)²`，所省为 `x² - (x-1)² = 2x - 1`。峰愈高，一刀所省愈多。故每一令，皆当削在当前最高峰上。”

智叟复问：“既总削最高峰，何以成层？”

愚公曰：“若总削最高峰，则最高者先降至次高，二者并齐；再一起降，及至第三高。故前 `i` 个峰会并成同高，为 `diff[i-1]`，下一层为 `diff[i]`。将前 `i` 个峰整层削至下一层，每峰削去 `diff[i-1] - diff[i]` 寸，总耗 `cost = i * (diff[i-1] - diff[i])`。批量而削，省锄省力，岂不妙哉？”

智叟沉吟片刻，曰：“妙则妙矣，若 `k` 不足整层削平，又当如何？”

愚公曰：“若 `k` 不足，便均摊。令 `q, r = divmod(k, i)`，前 `i` 个峰每个先降 `q` 寸，再挑 `r` 个再各补一刀。如此，峰虽未尽平，平方和已压到最低。何也？平方和喜平不喜尖，等高最省。”

操蛇之神闻之，惧其不已也，告之于帝。

帝感其巧，复命夸娥氏二子下界，依层而削，按余补刀。须臾，峰平差灭。

自此，冀之南，汉之阴，无过路费焉。

```python
n = len(diff)
for i in range(1, n):
    cost = i * (diff[i - 1] - diff[i])
    
    if cost <= k:
        k -= cost
        continue
    
    h = diff[i - 1]
    q, r = divmod(k, i)
    h0 = h - q
    
    return (
        (i - r) * h0 ** 2
        + r * (h0 - 1) ** 2
        + sum(x * x for x in diff[i:n])
    )

return 0
```
