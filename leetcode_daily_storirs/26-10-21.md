## 五大结局：AOE 管够，全屏禁用

看到“排序”“最小操作次数”，你是不是准备数逆序对了？

恭喜，你的条件反射非常健康，非常标准，只是——今天这题给的不是“交换两个字符”的单体平A，而是 `sort(l, r)` 这种区间 AOE：一发下去，`[l, r]` 里的逆序对全家桶一锅端。

但福利背面通常印着使用限制：**不能对整个字符串释放**。嗯，真子串随便排，但你别想 `sort(0, n)` 一键下班。

------

#### **核心洞察：先盯两端**

排好序的字符串有个铁律：第 0 位必须站着**全局最小值 mn**，最后一位必须蹲着**全局最大值 mx**。

题目又偏偏不让一次排序同时覆盖两端——整串排序是禁术。

所以问题就变成：需要用几次区间sort，才能把这两位大佬送回各自的端点？毕竟中间那群吃瓜群众，一次大范围排序就能顺手捋顺。

盘点一下手里的技能：

- 能改变首位的操作：**`sort(0, r)`** 。只要 `mn` 落在 `[0, r]` 里，就能把它送进 0 号位。
- 能改变末位的操作：**`sort(l, n-1)`** 。只要 `mx` 落在 `[l, n-1]` 里，就能把它送到 n-1 号位。
- 碰不到首尾的中间排序 **`sort(l, r)`**（l > 0 且 r < n-1） ？技能特效拉满，对端点伤害为零。

所以，是一发入魂、两发收工、还是三发拉扯，就看这两位大佬 `mn` 和 `mx` 开局站哪。

------

#### **分类讨论：五个结局**

**1. 先看字符串有没有自己躺好？**

如果字符串已经非降序，那还打什么？领题即领分：

```python
if all(s[i] <= s[i + 1] for i in range(n - 1)):
    return 0
```

**2. 只有两个字符的绝望局**

走到这说明字符串无序。如果它只有两个字符：真子串只剩单字符，排了毫无变化；选整个又违规。无解：

```python
if n == 2:
    return -1
```

**3. 一发能成吗？**

排除了上面两种，现在字符串长度至少为3，且无序。

如果首字符已经是 `mn`，一次 `sort(1, n-1)` 收工；如果尾字符已经是 `mx`，一次 `sort(0, n-2)` 收工：

```python
mn, mx = min(s), max(s)
if s[0] == mn or s[-1] == mx:
    return 1
```

**4. 两发能成吗？**

现在首字符不是 `mn`，尾字符也不是 `mx`。先看看这俩大佬有没有躲在中间：

- 如果 `mn` 在中间，先 `sort(0, pos(mn))` 把 `mn` 抬到 0 号位；再 `sort(1, n-1)` 把剩下的排好
- 如果 `mx` 在中间，先 `sort(pos(mx), n-1)` 把 `mx` 送到末尾；再 `sort(0, n-2)` 收尾。
- 如果两个都在中间，先拽谁都行——反正剩下那半段一次排序收尾，最后都会各就各位。

```python
tmp_s = s[1:-1]
if mn in tmp_s or mx in tmp_s:
    return 2
```

**5. 首最大、尾最小的尴尬局**

前面全没中，那么此时 `mn` 不在首位、也不在中间，那它只能在末位 `s[-1] == mn`；`mx` 不在末位、也不在中间，只能在首位 `s[0] == mx`。

最小值蹲在最后一格，最大值站在第一格，两大佬互相卡位，怎么办？三段式挪车：

1. `sort(1, n-1)`：先把尾部的 `mn` 捞到前面来（排完 `mn` 正好落在位置 1）；
2. `sort(0, 1)`：两大佬当面换座位—— `mn` 到 0 号位， `mx` 到 1 号位；
3. `sort(1, n-1)`：把 `mx` 踢到末尾，同时把其余部分排好。

```python
return 3
```

------

五个分支互斥且穷尽：任意字符串必落其一。所以答案只可能是 `-1, 0, 1, 2, 3`。

完整代码：

```python
def minOperations(s: str) -> int:
    n = len(s)
    
    # 0：已经非降序，领题即领分
    if all(s[i] <= s[i + 1] for i in range(n - 1)):
        return 0
    
    # -1：两个字符的绝望局，技能栏全灰
    if n == 2:
        return -1

    mn, mx = min(s), max(s)
    # 1：一端已经站对人，临门一脚
    if s[0] == mn or s[-1] == mx:
        return 1

    # 2：大佬藏在中间，先拽到端点，再一发清场
    tmp_s = s[1:-1]
    if mn in tmp_s or mx in tmp_s:
        return 2

    # 3：首最大、尾最小，三段式挪车
    return 3
```

时间复杂度 `O(n)`，空间复杂度 `O(n)`（因为切了个 `tmp_s`，想省内存也可以直接扫下标）。
