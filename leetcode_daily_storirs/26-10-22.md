## 挂着"排序"的名，干着盘串的活

这题叫"排序排列"，配了两个操作：**反转整个数组**、**左旋一位**。

如果你把这俩操作往一串首尾打结的手串上一摊，潘家园的大爷能当场从马扎上弹起来：“小伙子，你这就是文玩基本功啊！”

- **反转整个数组** = 把手串翻个面，左右镜像；
- **左旋一位** = 捻一颗珠子，换个起点接着盘。

捻也好，翻也好，盘久了你总会悟出一个残酷的真相：**相邻的珠子永远相邻**。每颗珠子的左右邻居是谁，从穿串打结那一刻就焊死了。

------

#### 先看这串能不能盘活

目标串，接成环长这样：`0 - 1 - 2 - ... - n-1 - 0`。一路 `+1`，首尾一接，`n-1` 拐回 `0`——整圈就这一处绳结回卷。

既然邻居动不了，你的串想跟目标串对上号，只有两种可能：

- 同向：你的串也一路 +1（递增环），只要转到对的起点，就跟目标串一模一样；
- 反向：你的串是一路 -1（递减环），正好是目标串的镜像，翻个面就贴上了。

如果沿串走一圈，两个方向双双判假——那这串就是被人拆了、又胡乱串回去的：转再多圈、翻再多面也救不回来，`-1` 退货。

```python
prev = nums[-1]  # 环形前驱：最后一对是 (nums[-1], nums[0])
fwd = bwd = True

for x in nums:
    if fwd and not (x == prev + 1 or (prev == n - 1 and x == 0)):
        fwd = False  # 递增环：只允许 +1，以及唯一一次 n-1 -> 0 回卷
    if bwd and not (x == prev - 1 or (prev == 0 and x == n - 1)):
        bwd = False  # 递减环：只允许 -1，以及唯一一次 0 -> n-1 回卷
    if not fwd and not bwd:
        return -1
    prev = x
```

#### 再算最少操作数

串有救，剩下就是算账：从当前状态盘成目标串，最少几步？

**情况一：递增环**

递增环就是目标串被左旋过若干次。先定位 0 号珠：`p = nums.index(0)`。然后两种盘串手法：

- **老实捻**：左旋 `p` 次，把 0 号珠送到绳结起点，整串立马顺溜。代价：`p` 。
- **翻面抄近道**：要是 0 号珠快挨着尾巴了（`p` 逼近 `n`），老实捻能把手捻抽筋。不如先翻个面，左旋 `n−p` 下，再翻回来。代价 `n-p+2`。

取小的那个：`min(p, n-p+2)`。

**情况二：递减环**

递减环是目标串的镜像，肯定得有一次翻面。定位 `n-1` 号珠： `q = nums.index(n - 1)`。同样两种手法：

- **先捻后翻**：左旋 `q` 次把 `n-1` 送到起点，整串成 [n-1, ..., 0] 完美倒序，再一个翻面收工。代价 `q + 1`。
- **先翻后捻**：先翻面，递减变递增，再左旋 `n - q` 次。代价 `n - q + 1`。

还是挑小的：`min(q+1, n-q+1)`。

```python
def minOperations(nums: List[int]) -> int:
    n = len(nums)
    if n == 1:  # 就一颗，天然有序
        return 0

    prev = nums[-1]
    fwd = bwd = True

    for x in nums:
        if fwd and not (x == prev + 1 or (prev == n - 1 and x == 0)):
            fwd = False

        if bwd and not (x == prev - 1 or (prev == 0 and x == n - 1)):
            bwd = False

        if not fwd and not bwd:
            return -1  

        prev = x

    if fwd:
        p = nums.index(0)  # 0 号珠到起点的距离
        return min(p, n - p + 2)  # 老实捻 p 次，或翻面抄近道 n-p+2

    q = nums.index(n - 1)  # n-1 号珠到起点的距离
    return min(q + 1, n - q + 1)  # 先捻后翻 / 先翻后捻，挑近的 
```

一趟遍历判环，一次 `index` 定位，时间 `O(n)`，空间 `O(1)`。

顺带附赠一个装杯知识点：这题的数学真身，是**正 n 边形的对称群 Dₙ，学名二面体群**——n 种转法配 n 种翻法，共 2n 个姿态。但你压根不用枚举这 2n 种，"邻居关系"四个字，早把答案焊死了。
