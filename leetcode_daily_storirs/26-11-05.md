## 摸鱼的第一性原理：最近的老板有多远

把数轴想成公司那条长走廊，门牌号从 `-1000` 排到 `1000`。

- `arr2` 是各位老板 `boss` 的工位，老板们自带“抬头扫视半径” `d`：一抬眼，左右 `d` 米内的屏幕尽收眼底。
- `arr1` 是 HR 甩给你的候选工位 `desk` 清单：“兄弟，这些位置你看看。”
- 问：清单里有几个工位能安心摸鱼？

答案很朴素：只要这个候选工位方圆 `d` 米内没有任何老板，它就是摸鱼圣地。

换句话说，对于候选工位 `desk`，必须满足——对所有老板 `boss`，都有 `|desk - boss| > d`。

注意是严格大于。只要存在一个老板满足 `|desk - boss| <= d`，这工位就不行——毕竟他能瞄到你，自然也能看清你屏幕上的 B 站。

------

**一：朴素的暴力**

数据规模 `arr1.length, arr2.length <= 500`，最多检查 `500 × 500 = 250000` 次。
还没你上班一天点开微信的次数多，暴力完全够。

对每个候选工位 `desk`，遍历所有老板工位 `boss`：

- 如果发现 `|desk - boss| <= d`：淘汰，HR 下一个。
- 如果所有老板都看不见：`ans++`，摸鱼工位 +1。

```python
def findTheDistanceValue(arr1, arr2, d):
    ans = 0
    for desk in arr1:
        safe = True
        for boss in arr2:
            if abs(desk - boss) <= d:
                safe = False
                break
        if safe:
            ans += 1
    return ans
```

复杂度：时间 `O(n * m)`，空间 `O(1)`。

------

**二：排序 + 二分**

暴力虽然能过，但每次都让全公司老板跟你挨个对视，场面多少有点尴尬。

换个角度想：对候选工位 `desk` 来说，真正的“危险区”是哪一段？

答案是闭区间 `[desk - d, desk + d]`。
只要这个区间里一个老板都没有，你就可以放心摸鱼；只要混进去哪怕一位，工位秒变直播间。

所以问题从“挨个审问老板”变成了：**这段危险区里，到底有没有老板？**

先把老板工位 `arr2` 排好序，然后用 `bisect_left` 找**第一个**坐在危险区左边界上或右边（`>= desk - d` ）的老板：

- 如果根本没找到（`idx == len(arr2)`），说明所有老板都坐在 `desk - d` 左边。危险区里空无一boss，摸鱼圣地 +1，你甚至可以站起来做套广播体操；
- 如果这位老板已经站得比危险区右边界还远（`arr2[idx] > desk + d`），那排在他前面的老板统统在 `desk - d` 左边，排在他后面的只会更靠右。危险区被老板们完美绕过，依然是空的——摸鱼圣地 +1；
- 否则，这位老板正好落在 `[desk - d, desk + d]` 里——共享屏幕，社死预定。

```python
def findTheDistanceValue(arr1, arr2, d):
    ans = 0
    arr2.sort()
    for desk in arr1:
        idx = bisect_left(arr2, desk - d)
        if idx == len(arr2) or arr2[idx] > desk + d:
            ans += 1
    return ans
```

复杂度：排序 `O(m log m)`，n 次二分 `O(n log m)`，合计 `O((n + m) log m)`，额外空间 `O(1)`（不计排序开销）。

------

**尾声**

老板密度决定公司规模，老板距离决定你的切屏速度。

- 暴力版：挨个问候全公司老板，图个心安。新人标配——不是勤快，是还没摸清敌情。
- 二分版：只查危险区左门口那一位。老油条标配——不是偷懒，是精准防御。

真正决定你能不能摸鱼的，从来不是公司有多少老板，而是离你最近的那位有多远。

500 个老板和 5 个老板，只要你坐对了位置，都是岁月静好，屏幕常亮；反过来，哪怕全公司只有一个老板，只要他坐你隔壁，你的屏幕上就只剩 IDE。
