

## 昨天数摸鱼，今天两个堆调度全机房

昨天，你滑得一手好窗，轻松盘清“过去 `x` 分钟有几台服务器在岁月静好”。临下班，老板意味深长补了一刀：

> “它们是真的闲，还是负载不均的受害者？”

你还没来得及回答，今天老板就把一沓任务表拍你工位上：“既然你能数清楚谁在摸鱼，那就由你来派活。”

`n` 台服务器，`m` 个任务。每台服务器有一个权重，每个任务有一个耗时。第 `j` 个任务在第 `j` 秒准时到达——注意，不是一次性全来，是按时间陆续到达的，像极了老板的灵感，一阵一阵的。

分配规则：空闲服务器里，选**权重最小**的；权重相同，选**下标最小**的；没有空闲的，就等有服务器空出来再派。

你需要输出每个任务被分配到了哪台服务器。

机房里 `n` 台服务器一字排开，指示灯明明灭灭。那一刻，你感觉自己不像在敲代码，倒像个登上点将台的将军——底下一整片服务器大军列阵待发，只等你一声令下，把每道军令派给最趁手的那个兵。

------

**一、两个堆：摸鱼堆 vs 运行堆**

将军点兵，从不逐个营帐去问“兄弟，闲吗”——他先列阵。

机房里的服务器也一样。任意时刻，每台服务器只有两种状态：**闲着**，或者**忙到某个时刻**。

状态不同，列阵规则也不同：闲着的，比的是“谁更该被派出去”——权重小者优先，权重撞车则工号小者优先；忙着的，比的是“谁先干完”——释放时刻早者优先。

一个堆只认一种排序键，两套规矩硬塞不进同一个堆。那就分营列阵，各排各的队：

- **摸鱼堆 `idle`**：所有空闲服务器，按 `(权重, 工号)` 排小顶堆。堆顶永远是“最该被选中”的那台——权重最小，权重相同则工号最小，妥妥的性价比之王，派活时直接薅它。
- **运行堆 `busy`**：所有在干活的服务器，按 `(释放时刻, 工号)` 排小顶堆。堆顶永远是“最早干完”的那台——一交差，立刻捞回 `idle` 堆，等待下一轮点将。

是不是看着有点眼熟？这两个堆，像极了操作系统里的“就绪队列 + 运行队列”：就绪队列等着被调度，运行队列记着谁什么时候干完，有时钟推进，有事件驱动。

只不过这里调度的不是进程，是服务器。将军也不是操作系统，是你。

------

**二、两根指针：挂钟 `now` 和任务编号 `tid`**

将军点将，得盯着两样东西：时辰和手里那叠军令。派活也一样，攥两根指针就够了：

- `tid`：下一个要派出去的任务编号，从 `0` 一路涨到 `m-1`，只增不减——派出去的活，没有收回来的道理。
- `now`：机房挂钟。第 `tid` 个任务在 `tid` 秒才到达，所以派第 `tid` 个任务时，挂钟必须已经走到 `tid` 秒——你不是预言家，任务没到就是没到。

外层一个主循环：只要还有任务没派完，就一轮一轮往下转。

每一轮，干三件事。

------

**三、一轮三件事：收兵 → 点兵 → 拨钟**

**① 收兵。** 盯住运行堆 `busy` 的堆顶：只要 `busy[0][0] <= now`，就弹出、捞回摸鱼堆 `idle`。它们早就干完了，重新按 `(权重, 工号)` 列队待命——下一轮点兵，还是“谁便宜谁先上”。

**② 点兵。** 内层 `while tid < m and tid <= now and idle`：只要**还有任务没派完**、**任务已到**、**摸鱼堆还有兵**，就连续点兵——从摸鱼堆薅走堆顶那台服务器，记下这活派给了谁（`ans[tid]`），再算出它的释放时刻 `now + tasks[tid]`，塞进运行堆 `busy`。`tid += 1`，接着处理下一个活。

题目那句“同一时刻存在多台空闲服务器，可以同时将多项任务分别分配给它们”，全靠这个内层 `while` 兜住——一次拨钟，把能派的全派干净，绝不留到下一秒。

**③ 拨钟。** 派不动了（要么任务没到，要么没兵可派），就推进挂钟：`now = busy[0][0] if not idle else tid`。

- 摸鱼堆 `idle` 为空：所有服务器都在忙，就算有任务到了也没人接 → 挂钟**快进**到最早干完那台的释放时刻 `busy[0][0]` ——没兵可派，就等打完仗的兵回营。
- 摸鱼堆 `idle` 还有兵：说明只是任务没到（`tid > now`）→ 挂钟跳到下一个任务的到达时刻 `tid`（第 `tid` 个任务在 `tid` 秒到达）——有兵有闲，只等军令到。

两种拨法都保证 `now` 只进不退，而且每一轮**必有进展**——要么推进至少一个任务（`tid` 前进），要么挂钟往前跳，所以绝不会死循环。

一句话总结：**idle 空，等服务器；idle 不空，等任务。调度器从不空转，时钟只往有事件的地方跳。**

```python
def assignTasks(servers: List[int], tasks: List[int]) -> List[int]:
    m = len(tasks)
    # 摸鱼堆：空闲机器按 (权重, 工号) 排队，堆顶是最便宜的劳动力
    idle = [(w, sid) for sid, w in enumerate(servers)]
    heapq.heapify(idle)
    busy = []          # 运行堆：在干活的机器按 (释放时刻, 工号) 排队
    ans = [0] * m
    now = tid = 0      # now = 机房挂钟；tid = 任务编号，第 tid 个任务在 tid 秒到达

    while tid < m:     # 只要还有任务没派完，就一轮一轮转
        while busy and busy[0][0] <= now:
            _, sid = heapq.heappop(busy)
            heapq.heappush(idle, (servers[sid], sid))
        while tid < m and tid <= now and idle:
            _, sid = heapq.heappop(idle)
            ans[tid] = sid
            heapq.heappush(busy, (now + tasks[tid], sid))
            tid += 1
        if tid >= m:
            break
        now = busy[0][0] if not idle else tid

    return ans
```

每个任务派一次、每台服务器每次释放回堆一次，堆操作合计 `O((n + m) log n)`；两个堆最多装下 `n` 台服务器，空间 `O(n)`。
