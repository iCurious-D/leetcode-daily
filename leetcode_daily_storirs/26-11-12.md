## 三连阳确立主升浪，深度回调即是黄金坑

这道题最狠的两个字是：**严格**。

不是“涨了就算”，是“天天都得涨”；中间但凡有一天平了盘，或者绿了一下，这段连阳就当没发生过。股民管这叫“连阳断了”，力扣管这叫“子数组结束”，老板管这叫“趋势被破坏了，都怪散户”。

现在老板把某只票50天的收盘价甩给你——数组 `nums`，要求很朴素：“数数它最长连阳几天，我要写研报。”

你扫了一眼曲线：红、红、绿、平、绿……像心电图，还是抢救室那台。

“顺便”，老板头也不抬，“连阴也数一下。我要知道它是慢牛，还是自由落体。”

------

一、正则整活版

把相邻两天的涨跌写成 `+`、`-`、`0`，剩下的事交给正则：抓最长的红串，或者最长的绿串。

数值题做成字符串题——换个维度，工具库全是外挂。

```python
def longestMonotonicSubarray(nums):
    import re
    s = ''.join('+' if b > a else '-' if b < a else '0' for a, b in zip(nums, nums[1:]))
    return 1 + max(map(len, re.findall(r'\++|-+', s)), default=0)
```

能跑，但别在正经面试里突然掏外挂——面试官的表情会从“这小伙子有想法”变成“这小伙子有想法，但不多”。

------

二、双计数器版

收回外挂，老老实实看 K 线。没有花活，只有收盘结算。

两根计数器不会打架：今天收红，连阴必断；今天收绿，连阳必断——任意时刻永远只有一根在涨，另一根躺平。

断了为什么重置为 `1` 而不是 `0`？因为今天再绿，明天一旦翻红，今天就是连阳的起跑线。

```python
def longestMonotonicSubarray(nums):
    ans = 1          # 单日也算连阳
    inc = dec = 1    # inc: 当前连阳天数；dec: 当前连阴天数
    for i in range(1, len(nums)):
        if nums[i] > nums[i - 1]:    # 今天收红
            inc += 1                 
            dec = 1                  
        elif nums[i] < nums[i - 1]:  # 今天收绿
            dec += 1
            inc = 1
        else:                        # 平盘十字星,两根条一起炸
            inc = dec = 1
        ans = max(ans, inc, dec)     # 每天收盘，结算一次
    return ans
```

时间复杂度 `O(n)`，空间复杂度 `O(1)`。老板要的连阳连阴，一趟遍历全交差。

------

三、区间扫描版

双计数器是逐日结算：每天收盘记一笔。稳是稳，但像散户盯盘——每天四小时不离屏幕，盘还没崩，人先崩了。

区间扫描不记账，看的是**段**。真实行情本来就是成段的：主升浪一段，回调一段，横盘一段，偶尔再来个‘黄金坑’把追高的全埋进去。

逐日结算的人手里是流水，看段的人手里是趋势：平盘直接跳过；非平盘就锁方向，一路冲到方向变或者撞上平盘为止，整段结算，再把指针往回退一格，从拐点重新起步。

```python
def longestMonotonicSubarray(nums):
    n = len(nums)
    ans = 1
    i = 0
    while i < n - 1:
        if nums[i] == nums[i + 1]:   # 平盘跳过
            i += 1
            continue
        start = i                    # 本段起点
        inc = nums[i] < nums[i + 1]  # 先锁方向
        i += 2
        # 方向不变就一路冲，!= 防止平盘混进队伍
        while i < n and nums[i] != nums[i - 1] and (nums[i - 1] < nums[i]) == inc:
            i += 1
        ans = max(ans, i - start)
        i -= 1                       # 回退一格，从拐点重新起步
    return ans
```

注意最后那个 `i -= 1`。忘了它，你就会从拐点的下一格开始找下一段，把“拐点本身”漏掉。
